# ShipIt Supabase Toolkit — feature overview

This brief overview describes the product at a marketing level. It does not disclose source code, implementation details, or complete technical documentation.

- **Player accounts:** connect common player identity needs to the backend project you operate.
- **Game data:** support online player data and progression workflows.
- **Connected play:** build multiplayer-adjacent social and live game experiences around your own service setup.
- **Development workflow:** organize backend setup and project-side work from within Unity.

You bring and operate the backend project. The toolkit does not include a ShipIt-hosted service. See the website and product documentation for current scope, setup requirements, and security guidance.
